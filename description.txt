On the input we have an ADIOS2 dump of an MD simulation.
Hereafter I use box=cell, referring to the simulation box.
We have cubic (guaranteed) cell and atom' positions.
We will designate the cell edge length as $L$ and atom number as $N$.
However just in case functions still use all $L_x, L_y, L_z$.
Input atom positions are wrapped into the box (cell).

# Function `inscribed`:

We imagine a sphere, inscribed into the cube (cubic cell).
The sphere' radius is then $R_i=L/2$. The number of atoms in the sphere (average) $N_i=N \pi/6$.
What function should do is for atoms inside the inscribed sphere calculate:
$$
uc_i = \frac{3}{5}N_i^{2/3},
$$
$$
upex_i = \frac{1}{N_i}\sum_{i\ne j}\frac{1}{r_{ij}} - uc_i,
$$
$$
ubex_i = \frac{1}{2}\left(\frac{1}{N_i}\sum_{i}r_i^2 - uc_i\right)
$$
So I loop over i-th atoms, skip if not in sphere, then for each i-th atom loop over j-th atom. If both inside, calculate property.

# Function `circumscribed`:

We imagine a sphere, circumscribed over the cube (cubic cell).
The sphere' radius is then $R_c=L/\sqrt{2}$. The number of atoms in the sphere (average) $N_c=N \frac{\sqrt{2}\pi}{3}$.
We use periodic boundary conditions (PBC), therefore imagine images of atom and treat them as real atoms (that's intentional).
What function should do is for atoms inside the circumscribed sphere calculate the same properties, as `inscribed`:
$$
uc_c = \frac{3}{5}N_c^{2/3},
$$
$$
upex_c = \frac{1}{N_c}\sum_{i\ne j}\frac{1}{r_{ij}} - uc_c,
$$
$$
ubex_c = \frac{1}{2}\left(\frac{1}{N_c}\sum_{i}r_c^2 - uc_c\right)
$$
So I first create 6 additional images, therefore we have 7 sets of atoms. Loop over each pair and calculate.
